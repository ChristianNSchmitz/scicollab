TYPOGRAPHY

two faces · 7 sizes · 1.2 / 1.5
DEVIATION · CONFIRM
The v3 brand direction is monospace throughout. This system uses Inter for long-form body text at 14px and above — question bodies, answers, abstracts, protocol steps, descriptions — because pure monospace at body size is unreadable in dense scientific prose, where a single paragraph can run 400 words. All interface chrome stays JetBrains Mono. Founders: confirm or reject. Rejecting costs roughly 15% reading speed on long answers; accepting means the brand voice lives in the chrome, not the prose.

[ 07 ]

HARD RULES

enforced on every screen in every later batch
VISIBILITY IS PERMANENT
Every screen showing any artifact displays its visibility state as a persistent chip in the top-left of the main canvas — Private, Lab, Institution, Public, Embargoed. Never inside a settings modal.
AI RETRIEVES, NEVER RULES
No AI output ships without a visible, clickable source artifact and a path to human validation. AI surfaces and structures; the community validates.
DISCUSSION IS ADJACENT
Discussion is never its own destination. It renders beside the artifact it is about, inside the project that contains both.
